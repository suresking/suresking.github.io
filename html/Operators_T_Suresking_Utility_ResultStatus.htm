    ResultStatus 运算符

    运算符

    BitwiseAnd(ResultStatus, ResultStatus) 逻辑与运算符，用于实现 && 的短路求值。

    语义为"校验链"：
    - 若 left 成功，则继续返回 right（保留 right 的 Message）；
    - 若 left 失败，则直接返回 left（短路，right 不参与，保留 left 的 Message）。

    注意：Message 不做合并，返回的永远是"第一个失败结果"或"最后一个成功结果"的 Message， 中间成功结果的 Message 会被丢弃。

    BitwiseOr(ResultStatus, ResultStatus) 逻辑或运算符，用于实现 || 的短路求值。

    - 若 left 成功，则直接返回 left（短路，right 不参与）；
    - 若 left 失败，则返回 right。

    注意：Message 不做合并，中间结果的 Message 会被丢弃。

    False(ResultStatus) false 运算符：与 True(ResultStatus) 成对出现， 使 && / || 具备短路能力。
    True(ResultStatus) true 运算符：使 && 与 if 语句能基于 Success 进行短路判断。
