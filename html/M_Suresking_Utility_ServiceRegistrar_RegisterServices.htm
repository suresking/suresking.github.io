    ServiceRegistrarRegisterServices 方法

    扫描宿主程序集中的 ViewModel / View 并注册到容器，随后调用宿主回调注册自定义服务。

    扫描规则：

    • ViewModel：带 [SuresKingViewModel] 特性的具体类，批量注册。
    • View：带 [SuresKingView] 特性且继承 UserControl 的具体类，逐个注册自身类型。

    ViewModel 使用 RegisterMany 批量注册；View 使用逐个 Register， 避免把 UserControl 实现的系统接口（IComponent 等）一并注册进容器。

    本方法幂等：重复调用直接返回首次注册的容器，不会重复扫描或重复注册。

    C#
    public static IContainer RegisterServices(
	Assembly hostAssembly,
	Action<IContainer>? configureServices = null
)

    参数

    hostAssembly  Assembly
    宿主程序集，通常是 typeof(App).Assembly。

    必须由调用方显式传入，而不是在类库内部使用 Assembly.GetExecutingAssembly()： 本方法位于类库中，GetExecutingAssembly() 会返回类库自身的程序集， 扫描不到宿主的 View / ViewModel。

    configureServices  ActionIContainer  (Optional)
    宿主自定义服务注册回调。在类库完成 ViewModel / View 注册后调用， 宿主在此注册自己的服务（如数据服务、配置服务）和主窗口（如 MainWindow）。

    类库不关心宿主注册了什么，也不硬编码任何宿主类型。

    返回值

    IContainer
    已完成注册的 IContainer 实例。

    异常

    ArgumentNullException当 hostAssembly 为 null 时抛出。
    InvalidOperationException 当存在同名 View（不同命名空间下类名相同）时抛出，异常消息包含冲突类型的完整名称。
