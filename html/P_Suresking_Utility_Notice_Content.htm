    public Object? Content { get; }

    属性值

    Object

    备注

    当 Title 和 Message 无法满足需求时使用此属性传递结构化数据。

    典型使用场景：

    • Show：传递对话框的 ViewModel 或上下文对象。
    • ContentSwitch：传递目标视图标识或导航参数。
    • Command：传递指令名称及参数。
    • Custom：传递任意自定义数据。

    消费方可通过 TryGetContentT(T) 安全地提取指定类型的内容。
