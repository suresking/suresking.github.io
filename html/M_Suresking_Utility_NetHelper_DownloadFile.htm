    NetHelperDownloadFile 方法

    同步下载文件。

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.20+9f5f0e39c286801d0347077a3bcbea48de44d8b3
    C#
    public static ResultStatus DownloadFile(
	string remoteFile,
	string localFile
)

    参数

    remoteFile  String
    文件 URL，需为绝对地址。
    localFile  String
    本地保存路径（含文件名）；父目录不存在时会自动创建。

    返回值

    ResultStatus
    操作结果：成功时返回 Succeed； 失败时返回 Invalid(String) 并携带异常信息（同时写入日志）。

    备注

    此方法会阻塞当前线程，不建议在 UI 线程或对响应性敏感的场景中调用； 异步场景请使用 DownloadFileAsync(String, String, Int32) 或 DownloadFileWithProgressAsync(String, String, Int32, IProgressDouble, CancellationToken)。

    内部通过 ConfigureAwait(false).GetAwaiter().GetResult() 同步等待异步流， 存在一定死锁风险（在有同步上下文的线程中调用时），故更推荐异步版本。
