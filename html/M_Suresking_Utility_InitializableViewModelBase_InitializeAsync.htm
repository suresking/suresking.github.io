    InitializableViewModelBaseInitializeAsync 方法

    当派生类重写时，执行实际的异步初始化逻辑。 在此方法中实现数据加载、服务调用等初始化操作。

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.22+a27276bb8ffde055e69ff608e98aafba279e1e99
    C#
    protected abstract Task InitializeAsync(
	CancellationToken cancellationToken = default
)

    参数

    cancellationToken  CancellationToken  (Optional)
    用于取消初始化操作的取消令牌。

    返回值

    Task
    表示异步初始化操作的任务。

    备注

    此方法为 protected，仅供派生类实现，外部调用方不可见也不可调用。 外部调用方应使用 EnsureInitializedAsync(CancellationToken)： 它会管理 IsLoading / HasError / ErrorMessage 状态， 并保证并发调用下只执行一次初始化。

    派生类必须实现此方法以提供具体的初始化逻辑。 如果初始化失败，直接抛出异常即可——基类的 EnsureInitializedAsync(CancellationToken) 会捕获异常、更新错误状态，然后重新抛出。
