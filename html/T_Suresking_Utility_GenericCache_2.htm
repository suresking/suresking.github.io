    GenericCacheTKey, TValue 类

    提供泛型静态缓存功能 支持多线程并发访问 注意：不同的泛型参数类型会生成完全独立的缓存实例

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.22+a27276bb8ffde055e69ff608e98aafba279e1e99
    C#
    public static class GenericCache<TKey, TValue>
    Inheritance
    Object    GenericCacheTKey, TValue

    类型参数

    TKey
    缓存键的类型，必须为不可为null的类型
    TValue
    缓存值的类型

    属性

    Count 获取缓存项数量 此属性是线程安全的

    方法

    AddOrUpdate(TKey, TValue) 添加或更新缓存项 如果键不存在则添加，如果键存在则更新
    AddOrUpdate(TKey, FuncTKey, TValue, FuncTKey, TValue, TValue) 添加或更新缓存项（通过更新函数） 提供更灵活的值更新逻辑
    AddRange 批量添加缓存项 如果键已存在，则跳过该键值对
    Clear 清空所有缓存 同时清理同步缓存和异步缓存
    ContainsKey 检查指定缓存项是否存在 此方法只检查键是否存在，不关心对应的值
    ContainsValue 检查指定缓存值是否存在 此方法在缓存中搜索指定的值 注意：此操作的时间复杂度为O(n)，n为缓存项数量
    Get 获取缓存项 如果缓存中不存在指定的键，则返回默认值
    GetAllItems 获取缓存中的所有键值对 返回的列表是只读的，对缓存的修改不会影响此列表 注意：在缓存较大时，此操作可能会消耗较多内存
    GetByKey 通过键获取缓存项 如果键不存在，抛出KeyNotFoundException异常
    GetKeys 获取缓存中所有键的列表 返回的列表是只读的，对缓存的修改不会影响此列表 注意：在缓存较大时，此操作可能会消耗较多内存
    GetOrAdd 获取或添加缓存项 如果键不存在，则添加指定的值 此方法是原子操作，线程安全
    GetOrCreate(TKey, FuncTKey, TValue) 获取缓存项，如果不存在则通过带键参数的工厂函数创建并缓存 此方法是线程安全的，工厂函数在需要时最多执行一次
    GetOrCreate(TKey, FuncTValue) 获取缓存项，如果不存在则通过工厂函数创建并缓存 此方法是线程安全的，工厂函数在需要时最多执行一次
    GetOrCreateAsync(TKey, FuncTKey, TaskTValue) 异步获取缓存项，如果不存在则通过带键参数的异步工厂函数创建并缓存 此方法防止竞态条件，确保同一键的异步操作只执行一次
    GetOrCreateAsync(TKey, FuncTaskTValue) 异步获取缓存项，如果不存在则通过异步工厂函数创建并缓存 此方法防止竞态条件，确保同一键的异步操作只执行一次
    GetValues 获取缓存中所有值的列表 返回的列表是只读的，对缓存的修改不会影响此列表 注意：在缓存较大时，此操作可能会消耗较多内存
    Remove(TKey) 移除指定缓存项 不会抛出异常，即使键不存在也会返回false
    Remove(TKey, TValue) 移除指定缓存项并返回移除的值 如果键存在，返回被移除的值；如果不存在，返回default(TValue)
    TryGet 尝试获取缓存项 不会抛出异常，通过返回值表示是否获取成功
    TryUpdate 更新缓存项 仅当当前值与比较值相等时才更新为新值 此方法是原子操作，线程安全
