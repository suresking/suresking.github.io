    DoubleExtension 类

    提供浮点数（double）的安全比较和运算扩展方法。

    备注

    浮点数由于精度问题，直接用 ==、>、< 比较可能得到错误结果。

    本类方法通过引入误差容限（tolerance）来安全比较浮点数。

    使用示例：

    double a = 0.1 + 0.2; // 实际是 0.30000000000000004 double b = 0.3; bool equal = a.AlmostEquals(b); // true bool greater = a.GreaterThan(b); // false bool lessEqual = a.LessOrEqual(b); // true bool nearZero = (a - b).IsNearZero(); // true double result = a.SafeDivide(b); // 安全除法

    方法

    AlmostEquals 安全的浮点数相等比较。
    GreaterOrEqual 比较当前值是否大于等于另一个值（考虑浮点误差）。
    GreaterThan 比较当前值是否大于另一个值（考虑浮点误差）。
    IsNearZero 判断当前值是否接近零。
    IsSpecialValue 判断当前值是否为 PositiveInfinity、NegativeInfinity 或 NaN。
    LessOrEqual 比较当前值是否小于等于另一个值（考虑浮点误差）。
    LessThan 比较当前值是否小于另一个值（考虑浮点误差）。
    NotAlmostEquals 安全的浮点数不相等比较。
    SafeDivide 安全的浮点数除法，分母接近零时返回默认值。
