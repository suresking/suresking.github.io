    PowerShellHelper 类

    提供执行 Windows PowerShell 5.1 脚本的方法。

    备注

    支持的执行方式：

    • 执行 .ps1 脚本文件（同步 / 异步 / 带实时进度）

    • 直接执行脚本字符串（同步 / 异步 / 带实时进度）

    • 执行内联命令（-Command）

    所有执行方式均固定以 -NoProfile -NonInteractive 运行，并使用 GBK(936) 编码读写输出， 以适配中文 Windows 环境下的中文脚本与输出。

    使用示例：

    // 执行脚本文件（同步） var r = PowerShellHelper.ExecuteFile(@"D:\scripts\build.ps1"); Console.WriteLine(r.ExitCode); Console.WriteLine(r.Output); // 执行脚本文件（异步 + 参数 + 超时） using var cts = new CancellationTokenSource(TimeSpan.FromMinutes(5)); var r2 = await PowerShellHelper.ExecuteFileAsync( @"D:\scripts\build.ps1", arguments: "-Configuration Release", cancellationToken: cts.Token); // 执行内联命令 var r3 = await PowerShellHelper.ExecuteCommandAsync( "Get-Process | Select-Object -First 5"); // 直接跑一段脚本字符串 var r4 = await PowerShellHelper.RunScriptTextAsync(@" $sum = 1..10 | Measure-Object -Sum | Select-Object -ExpandProperty Sum Write-Output ""Sum=$sum"" exit 0 "); // 实时进度 var progress = new Progress<string>(Console.WriteLine); var code = await PowerShellHelper.ExecuteFileWithProgressAsync( @"D:\scripts\build.ps1", progress: progress);

    属性

    ExecutablePath PowerShell 可执行文件路径。默认固定为 Windows PowerShell 5.1（"powershell.exe"）。
    OutputEncoding 输出/错误流的编码。默认 GBK(936)，适配中文环境。

    方法

    ExecuteCommandAsync 异步执行一段内联 PowerShell 命令并获取输出。
    ExecuteFile 同步执行 PowerShell 脚本文件并获取输出。
    ExecuteFileAsync 异步执行 PowerShell 脚本文件并获取输出。
    ExecuteFileWithProgressAsync 异步执行 PowerShell 脚本文件，并实时报告每一行输出。
    RunScriptText 同步执行一段 PowerShell 脚本字符串并获取输出。
    RunScriptTextAsync 异步执行一段 PowerShell 脚本字符串并获取输出。
    RunScriptTextWithProgressAsync 异步执行一段脚本字符串，并实时报告每一行输出。
