    IHisConfig 属性

    属性

    ChineseDispenseFile中药发药文件名（可选）
    ChineseLibraryDetailFile中药库库存明细文件名（可选）
    ChineseLibraryInventoryFile中药库库存余额文件名（可选）
    ChinesePharmacyDetailFile中药房库存明细文件名（可选）
    ChinesePharmacyInventoryFile中药房库存余额文件名（可选）
    DebugMode 调试模式标志（HIS导出目录下存在 debug.txt 即为 true）

    若 HisExportRoot 未配置或目录不存在，返回 false，不抛异常

    ExtendSetting 扩展配置字典（只读视图）。键为 JSON 顶层的属性名，值为对应的 JsonElement。 外部只能读取，无法添加、删除或替换；内部由实现方在 LoadSetting 时整体替换。 始终非 null，加载失败或文件缺失时为空字典，调用方无需判空。
    HisExportRoot HIS系统导出文件的根目录（必填，可读写）

    典型值为：D:\HealthOne - 盛德\Export

    HtmlExportRoot 导出 html 的根目录（一般为 nginx 的 html 子目录绝对路径）
    NetDataRoot 需要联网保存数据的根目录（一般为坚果云对应项目的绝对路径）
    WesternDispenseFile西药发药文件名（可选）
    WesternLibraryDetailFile西药库库存明细文件名（可选）
    WesternLibraryInventoryFile西药库库存余额文件名（可选）
    WesternPharmacyDetailFile西药房库存明细文件名（可选）
    WesternPharmacyInventoryFile西药房库存余额文件名（可选）
