    ZipHelperDecryptAndDecompressFromFile 方法

    从二进制文件解密并解压，还原为字符串。

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.22+a27276bb8ffde055e69ff608e98aafba279e1e99
    C#
    public static ResultStatus DecryptAndDecompressFromFile(
	string archiveFilePath,
	string? password = null
)

    参数

    archiveFilePath  String
    压缩文件完整路径。
    password  String  (Optional)
    解密密码；为 null/空 时按未加密处理。

    返回值

    ResultStatus
    操作结果：成功时通过结果对象携带还原的字符串；失败时携带错误信息。

    备注

    处理流程：

    1. 读取二进制文件；
    2. 若 password 非空，则先经 CryptoStream（AES）解密；
    3. 再经 GZipStream 解压；
    4. 按 UTF-8 解码为字符串。

    流链顺序：FileStream → CryptoStream(Decrypt) → GZipStream → StreamReader。

    异常处理：

    • CryptographicException：密码错误或密文被篡改，转为失败状态；
    • InvalidDataException：文件不是有效 GZip 流或已损坏，转为失败状态；
    • 其它运行时异常：捕获后转为失败状态。

    返回值约定：本方法用 Valid(String) 承载还原的字符串。 若你的 ResultStatus 不支持在“成功状态”中承载业务数据，建议改为 out string? text 或返回元组 (ResultStatus, string?)，避免把业务数据塞进消息字段。

    异常

    ArgumentExceptionarchiveFilePath 为空。
