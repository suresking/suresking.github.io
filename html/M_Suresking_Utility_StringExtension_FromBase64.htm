    StringExtensionFromBase64 方法

    从 Base64 解码字符串

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.22+a27276bb8ffde055e69ff608e98aafba279e1e99
    C#
    public static string FromBase64(
	this string base64,
	Encoding? encoding = null
)

    参数

    base64  String
    Base64 字符串；为 null 或空时返回空字符串。
    encoding  Encoding  (Optional)
    解码后字节转字符串所用编码；为 null 时使用 UTF-8。

    返回值

    String
    解码后的字符串；输入非法 Base64 时返回 Empty（不抛异常）。

    备注

    在 Visual Basic 和 C# 中，这个方法可以当成为类型 String 的实例方法来调用。在采用实例方法语法调用这个方法时，请省略第一个参数。请参考 扩展方法 (Visual Basic) 或 扩展方法 (C# 编程指南) 获取更多信息。

    备注

    与 ToBase64(String, Encoding) 互为逆操作；解码失败被静默吞掉，如需区分“空输入”与“解码失败”请改用 FromBase64String(String)。
