    Notice 类

    表示一条通信消息，由消息类型、标题文本、消息文本和附加内容组成。

    备注

    核心设计：

    标题和消息文本是最常用的字段，直接以 String 类型暴露，方便简单场景快速使用。

    需要传递复杂对象（如视图模型、指令参数、配置项）时，使用 Content 属性。

    实例创建后不可修改（不可变对象），确保消息传递过程中的线程安全性和一致性。

    创建示例：

    // 纯文本消息——最常用 var msg = Notice.FromMessage("操作成功"); // 带标题的通知 var notify = Notice.FromTitleAndMessage("提示", "保存成功，共处理 100 条记录。"); // 仅标题——更新状态栏 var status = Notice.FromTitle("就绪"); // 内容切换——导航到指定视图 var nav = Notice.FromContentSwitch(new { Target = "UserProfile", UserId = 42 }); // 通用指令——触发刷新 var cmd = Notice.FromCommand(new { Action = "Refresh", Scope = "All" }); // 显示控制——弹出对话框 var dialog = Notice.FromShow(new MyDialogViewModel()); // 队列操作——入队消息 var enqueue = Notice.FromQueue(new { Action = "Enqueue", Item = new MyMessage() }); var enqueue = Notice.FromQueue("最简单的就是仅仅传递一个字符串用于队列显示"); // 自定义扩展 var custom = Notice.FromCustom(new { Reason = "SpecialCase", Payload = ... });

    属性

    Content 获取附加内容（复杂对象）。
    Empty 获取空通知实例，类型为 None。
    Message 获取消息文本。仅在 Type 为 MessageOnly 或 TitleAndMessage 时有值。
    Title 获取标题文本。仅在 Type 为 TitleOnly 或 TitleAndMessage 时有值。
    Type 获取消息类型，决定消费方如何解读本消息。

    方法

    Deconstruct 解构为元组，方便在模式匹配中使用。
    FromCommand 创建一条通用指令/操作通知，用于触发特定的业务逻辑。
    FromContentSwitch 创建一条内容切换通知，用于导航、视图切换、页面跳转等场景。
    FromCustom 创建一条自定义扩展通知，用于上述类型无法覆盖的特殊场景。
    FromMessage 创建一条仅包含消息文本的通知。
    FromQueue 创建一条队列操作通知，用于管理消息队列的生命周期和数据处理流程。
    FromShow 创建一条显示/可用状态通知，携带可选上下文对象。
    FromTitle 创建一条仅包含标题的通知。
    FromTitleAndMessage 创建一条包含标题和消息文本的完整通知。
    ToString 返回消息的字符串表示，用于调试和日志记录。
    (重写 ObjectToString)
    TryGetContentT 尝试将 Content 转换为指定类型。
