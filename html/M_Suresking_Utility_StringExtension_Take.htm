    取字符串前length个字符

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.22+a27276bb8ffde055e69ff608e98aafba279e1e99
    C#
    public static string Take(
	this string? s,
	int length
)

    参数

    s  String
    源字符串；为 null 或空时返回空字符串。
    length  Int32
    要保留的字符数；必须 ≥0。

    返回值

    String
    源字符串长度大于 length 时返回前 length 个字符，否则原样返回。

    备注

    在 Visual Basic 和 C# 中，这个方法可以当成为类型 String 的实例方法来调用。在采用实例方法语法调用这个方法时，请省略第一个参数。请参考 扩展方法 (Visual Basic) 或 扩展方法 (C# 编程指南) 获取更多信息。

    备注

    按 UTF-16 代码单元截取，对代理对（emoji 等）可能截断在半个字符处；如需按文本元素截取请使用 StringInfo。

    异常

    ArgumentOutOfRangeExceptionlength 为负数。
