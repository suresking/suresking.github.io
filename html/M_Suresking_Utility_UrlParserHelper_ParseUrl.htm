    public static UrlInfo ParseUrl(
	string url
)

    参数

    url  String
    完整的URL字符串，必须包含协议（如 https://example.com/a?x=1）。

    返回值

    UrlInfo
    包含URL各部分的解析结果 UrlInfo。

    备注

    各字段对应关系如下：

    • Scheme ← Scheme（如 "https"）
    • Host ← Host（不含端口）
    • Port ← Port（未显式指定时为协议默认端口，如 http=80、https=443）
    • Path ← AbsolutePath（以 "/" 开头）
    • LastSegment ← 路径最后一个 "/" 之后的部分
    • Query ← Query（以 "?" 开头，无查询时为空串）
    • QueryParameters ← 解析后的键值字典
    • Fragment ← Fragment（以 "#" 开头，无锚点时为空串）

    异常

    Exceptionurl 为 null 或空字符串时抛出（消息："网址参数不能为空~！"）。
    UriFormatExceptionurl 不是合法 URI（如缺少协议、含非法字符）时由 Uri 抛出。
