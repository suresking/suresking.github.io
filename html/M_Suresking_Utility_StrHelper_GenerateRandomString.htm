    C#
    public static string GenerateRandomString(
	int length = 16,
	bool includeNumbers = true,
	bool includeLowercase = true,
	bool includeUppercase = false,
	bool includeSymbols = false
)

    参数

    length  Int32  (Optional)
    字符串长度，默认为16；必须大于 0。
    includeNumbers  Boolean  (Optional)
    是否包含数字，默认为true
    includeLowercase  Boolean  (Optional)
    是否包含小写字母，默认为true
    includeUppercase  Boolean  (Optional)
    是否包含大写字母，默认为false
    includeSymbols  Boolean  (Optional)
    是否包含特殊符号，默认为false

    返回值

    String
    生成的随机字符串

    备注

    从所选字符集的并集中逐位等概率选取字符（非密码学安全随机数）。

    若需要密码学安全的随机字符串，请改用 RandomNumberGenerator 生成随机字节后映射到字符集。

    异常

    ArgumentException当所有字符类型都被禁用时抛出
