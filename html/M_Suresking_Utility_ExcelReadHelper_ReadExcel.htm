    public static List<Dictionary<string, string>> ReadExcel(
	string filePath,
	int headerRows = 2,
	Encoding? csvEncodingOverride = null
)

    参数

    filePath  String
    文件路径，支持 .xlsx、.xls、.csv 格式
    headerRows  Int32  (Optional)
    表头行数，1=单行表头，2=双行表头（默认）
    csvEncodingOverride  Encoding  (Optional)
    仅对 .csv 生效的编码覆盖项；为 null 时自动检测（BOM → 严格 UTF-8 → CharsetDetector → GB18030）。 读取 Excel（.xlsx/.xls）时忽略此参数。

    返回值

    ListDictionaryString, String
    字典列表，每个字典代表一行数据
