    备注

    两类功能：

    • 系统/UI 辅助：版本号读取、文件夹路径、消息框、文件对话框、文件导出、随机字符串。 其中消息框与文件对话框依赖 WPF（MessageBox、OpenFileDialog），需在 UI 线程使用。

    • 类型转换：以 ToT(String, T) / TryToT(String, T, T) 为统一入口， 内部按目标类型分派到 ToInt / ToDateTime / ToEnum 等具体方法。 所有转换方法均为“宽松解析 + 默认值兜底”，不抛异常，解析失败返回调用方提供的默认值。

    数值/日期解析约定：数值解析前会经 CleanNumericString(String) 清理货币符号、千位分隔符、 百分比等；日期解析按“预定义格式 → Excel 序列号 → Unix 时间戳 → 通用解析”的顺序依次尝试。

    属性

    Author 显而易见这是作者信息：）
    HostVersion 获取宿主应用版本（如 1.1.33）；非应用场景返回 "Unknown"
    MyDocuments 本机“我的文档”文件夹路径字符串

    其获取方法可作为其他特殊文件夹的参考

    Environment.GetFolderPath(Environment.SpecialFolder.MyDocuments)
    UserProfile 本机“用户目录”文件夹路径字符串

    其获取方法可作为其他特殊文件夹的参考

    Environment.GetFolderPath(Environment.SpecialFolder.UserProfile)
    Version 获取库自身版本（语义化版本，如 1.1.33）

    方法

    GenerateRandomString 生成指定长度的随机字符串
    GetFolderPath 通过保存文件对话框获取用户选择的文件夹路径
    OpenDialogGetFileName 打开文件选择对话框，获取单个文件路径
    OpenDialogGetFileNames 打开文件选择对话框，支持多选文件
    ShowMessage 使用 MessageBox 显示操作结果信息
    ShowWarningMessage 显示危险操作警告对话框，用户确认是否继续
    ToT 将字符串转换为指定类型
    ToBool 转换成Bool
    ToByte 转换成Byte
    ToDateTime 将字符串转换为 DateTime，支持超多格式
    ToDateTimeExact 将字符串转换为 DateTime（使用指定格式）
    ToDecimal 转换成Decimal
    ToDouble 转换成Double
    ToEnumT 转换成Enum
    ToFloat 转换成Float
    ToGuid 转换成Guid
    ToInt 转换成Int
    ToListT(IEnumerableString, T) 将字符串列表转换为指定类型的列表
    ToListT(String, Char, T) 将逗号分隔的字符串转换为指定类型的列表
    ToLong 转换成Long
    ToNullableDateTime 将字符串转换为 Nullable DateTime
    ToShort 转换成Short
    ToTimeSpan 转换成TimeSpan
    TryExportFile 将文本内容导出到指定文件
    TryExportFileWithDetail 将文本内容导出到指定文件（带详细错误信息）
    TryToT 尝试转换，返回是否成功
