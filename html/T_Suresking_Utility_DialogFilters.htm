    DialogFilters 类

    显示 OpenFileDialog 或 SaveFileDialog 之前设置 Filter 属性
    一般格式：dlg.Filter = "All Files|*.*"; dlg.DefaultExt = ".txt";
    也可以设置缺省文件名：dlg.FileName = "Document"; // Default file name

    备注

    本类提供若干常用筛选器的预置实例，供 OpenFileDialog / SaveFileDialog 的 Filter 与 DefaultExt 属性直接使用。

    注意：Extention 的值为通配形式（如 "*.txt"），传给 DefaultExt 时 按 WPF 约定会正常工作；但个别 API 期望不带星号的扩展名（".txt"），使用时请留意目标控件的实际要求。

    每个属性每次访问都会新建一个 DialogFiltersFilterType 实例，调用方修改返回值不会影响其他调用。

    属性

    All 所有格式的文件
    Csv Csv格式的文件
    Mp4 Mp4文件
    Office 早期office文件
    Office2007 office2007及更高版本文件
    Txt 纯文本文件
