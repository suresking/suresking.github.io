    SimpleExcelWriter 方法

    方法

    AddDataTable 从 DataTable 写入。数字列输出为数值单元格，DateTime 列输出 yyyy-MM-dd 文本。 headers 为 null 时用列名作表头；否则按顺序使用传入的表头（不要求与列数一致）。 withBorder 为 true（默认）时所有单元格加全边框。 返回写入的列数，便于调用 MergeFullRow 计算合并列数。
    AddListT 从 List<T> 写入。数字属性输出为数值单元格，DateTime 属性输出 yyyy-MM-dd 文本。 headers 为 null 时用属性名作表头；否则按顺序使用传入的表头（不要求与属性个数一致）。 withBorder 为 true（默认）时所有单元格加全边框。 返回写入的列数，便于调用 MergeFullRow 计算合并列数。
    AddMerge(String, Boolean) 添加合并单元格区域（例如 A1:C1）。 horizontalCenter 为 true 时该行水平居中（无边框），合并区域固定为某一行。
    AddMerge(Int32, Int32, Boolean) 合并某一行从第 1 列到第 colCount 列（等价于 AddMerge(MergeFullRow(row, colCount))）。 horizontalCenter 为 true 时该行水平居中（无边框）。
    AddRow手动添加一行，无边框。数字保留为数值单元格，DateTime 输出 yyyy-MM-dd 文本。
    AddRowAt(Int32, String) 新建一行，在第 position 列（1 起）放 contents，其余列均为空字符串，无边框。 例如 AddRowAt(3, "标题") 生成一行：["", "", "标题"]。
    AddRowAt(Int32, String) 新建一行，从第 position 列（1 起）开始依次写入 contents，前面的列均为空字符串，无边框。 例如 AddRowAt(3, "A", "B") 生成一行：["", "", "A", "B"]。
    Save(Stream)保存到流。流的生命周期由调用方负责。
    Save(String) 保存为 xlsx 文件。文件被其他程序占用（如 Excel 正打开）时抛出带路径的 IOException。
