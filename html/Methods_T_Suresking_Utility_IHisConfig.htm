    IHisConfig 方法

    方法

    GetConfiguredFileName按 key 获取已配置的文件名（不含根路径）
    GetConfiguredFileNames 获取所有已配置的文件名集合

    仅包含非空值；返回顺序由底层存储决定，不作顺序承诺

    GetConfiguredFullPath 获取指定键 key 对应文件的完整路径

    key 应取自 HisConfigKeys；自动拼接根目录和文件名

    GetConfiguredFullPaths 获取所有已配置文件的完整路径集合

    自动拼接根目录和文件名；返回顺序不作承诺

    GetConfiguredKeys 获取所有已配置的 key 集合

    仅包含已配置（非空）项的 key；返回顺序由底层存储决定，不作顺序承诺

    GetSettingT 从 ExtendSetting 中按键取值并转换为指定类型。 键不存在或转换失败时返回默认值，不抛异常。
    HasFile 检查指定文件名是否已配置
    LoadSetting 从 JSON 文件读取配置到 ExtendSetting。缺省使用程序同目录的 extendsettings.json。 文件不存在、为空、格式非法等情况不抛异常，保持原有内容不变。
    Validate 验证配置是否有效
