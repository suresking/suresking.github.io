    StrHelperToT 方法

    将字符串转换为指定类型

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.22+a27276bb8ffde055e69ff608e98aafba279e1e99
    C#
    public static T To<T>(
	this string value,
	T defaultValue = null
)

    参数

    value  String
    待转换的字符串；为 null 或空字符串时直接返回 defaultValue。
    defaultValue  T  (Optional)
    转换失败或输入为空时返回的默认值。

    类型参数

    T
    目标类型，可为可空类型（如 int?）。

    返回值

    T
    转换结果；无法转换时返回 defaultValue，不抛异常。

    备注

    在 Visual Basic 和 C# 中，这个方法可以当成为类型 String 的实例方法来调用。在采用实例方法语法调用这个方法时，请省略第一个参数。请参考 扩展方法 (Visual Basic) 或 扩展方法 (C# 编程指南) 获取更多信息。

    备注

    扩展方法，可直接以 "123".To<int>() 形式调用。

    内部先剥离 NullableT 得到底层类型，再按底层类型分派到具体转换方法： string/bool/数值/DateTime/TimeSpan/Guid/枚举各有专用逻辑，其余类型回退到 ChangeType(Object, Type, IFormatProvider)（使用不变区域性）。

    所有异常都被捕获并返回默认值，因此本方法“永不失败”，适合对脏数据做容错解析。
