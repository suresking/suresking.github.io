    XmlHelper 方法

    方法

    DeserializeFromXmlFileT(String) 从 XML 文件读取内容并反序列化为对象。
    DeserializeFromXmlFileT(String, NullableT) 从 XML 文件读取内容并反序列化为值类型。
    DeserializeFromXmlFileAsyncT(String, CancellationToken) 从 XML 文件异步读取内容并反序列化为对象。
    DeserializeFromXmlFileAsyncT(String, NullableT, CancellationToken) 从 XML 文件异步读取内容并反序列化为值类型。
    DeserializeFromXmlStringT(String) 将 XML 字符串反序列化为对象。
    DeserializeFromXmlStringT(String, NullableT) 将 XML 字符串反序列化为值类型或需要默认值的类型。 如果 XML 字符串为 null 或空白，返回 defaultValue。
    SerializeToXmlFileT 将可序列化对象序列化并保存到 XML 文件。
    SerializeToXmlFileAsyncT 将可序列化对象异步序列化并保存到 XML 文件。
    SerializeToXmlStringT 将可序列化对象序列化为 XML 字符串。
    TryDeserializeFromXmlStringT 尝试将 XML 字符串反序列化为对象，不抛出异常。
