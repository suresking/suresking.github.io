    SimpleExcelWriterAddRowAt(Int32, String) 方法

    新建一行，从第 position 列（1 起）开始依次写入 contents，前面的列均为空字符串，无边框。 例如 AddRowAt(3, "A", "B") 生成一行：["", "", "A", "B"]。

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.22+a27276bb8ffde055e69ff608e98aafba279e1e99
    C#
    public void AddRowAt(
	int position,
	params string?[]? contents
)

    参数

    position  Int32
    起始列位置（1 起）；小于 1 时按 1 处理。
    contents  String
    从起始列开始依次写入的内容；为 null 时视为空数组。

    备注

    生成的行总长度为 position - 1 + contents.Length，前面 position-1 列为空字符串。 数组元素为 null 时写为空字符串。
