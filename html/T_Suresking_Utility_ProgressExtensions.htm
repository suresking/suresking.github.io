    ProgressExtensions 类

    提供 IProgressT 的扩展方法，用于进度报告的格式转换。

    典型用途：库层（Library）对外暴露 IProgressT 数值型进度（如 IProgress<int>、 IProgress<double>），而 Service 层或 UI 层希望直接接收已格式化的字符串进度 （如 IProgress<string> 用于直接显示到状态栏/日志）。 本类通过适配器把数值进度自动转换为带前后缀、可自定义格式的字符串进度。

    所有方法均支持可空进度报告器：当传入的 IProgressT 为 null 时返回 null， 便于在"调用方不关心进度"的场景下直接透传而不产生额外分配。

    示例

    场景 1：默认格式（行数进度）

    C#
    public async Task ProcessAsync(IProgress<string>? progress)
{
    // 使用默认格式：已读取 {value} 行
    await library.ReadDataAsync(progress.AsProgress<int>());
    // 输出：已读取 128 行
}

    场景 2：自定义前后缀

    C#
    public async Task ExportAsync(IProgress<string>? progress)
{
    await library.ExportAsync(progress.AsProgress<long>("导出进度：", "%"));
    // 输出：导出进度：42%
}

    场景 3：百分比进度（保留 1 位小数）

    C#
    public async Task ProcessBatchAsync(IProgress<string>? progress)
{
    await library.ProcessBatchAsync(progress.AsProgress<double>(
        prefix: "处理进度：",
        suffix: "%",
        formatter: p => p.ToString("F1")
    ));
    // 输出：处理进度：75.5%
}

    场景 4：自定义复杂格式（元组进度）

    C#
    public async Task UploadAsync(IProgress<string>? progress)
{
    await library.UploadChunksAsync(progress.AsProgress<(int current, int total)>(
        prefix: "",
        suffix: "",
        formatter: v => $"上传中：{v.current}/{v.total} 块"
    ));
    // 输出：上传中：5/10 块
}

    场景 5：使用便捷封装方法

    C#
    public async Task ReadLinesAsync(IProgress<string>? progress)
{
    // 等价于 AsProgress<int>("已读取 ", " 行")
    await library.ReadLinesAsync(progress.AsIntProgress());

    // 等价于 AsProgress<double>("进度 ", "%", v => v.ToString("F0"))
    await library.DownloadAsync(progress.AsPercentageProgress());
}

    方法

    AsIntProgress 将 IProgressT（字符串）适配为 IProgressT（int）， 适用于普通的 int 计数型进度报告（如行数、条目数）。

    等价于调用 AsProgress<int>(prefix, suffix)。

    AsPercentageProgress 将 IProgressT（字符串）适配为 IProgressT（double）， 适用于百分比型进度报告，内部使用 "F0" 格式化为整数百分比。

    等价于 AsProgress<double>("进度 ", "%", v => v.ToString("F0"))。

    AsProgressT 将 IProgressT（字符串）适配为 IProgressT（任意类型）， 使库层的进度值自动转换为带描述文本的字符串进度。
