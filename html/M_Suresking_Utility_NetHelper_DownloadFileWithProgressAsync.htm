    NetHelperDownloadFileWithProgressAsync 方法

    带进度回调的异步流式下载，适合大文件。

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.22+a27276bb8ffde055e69ff608e98aafba279e1e99
    C#
    public static Task<ResultStatus> DownloadFileWithProgressAsync(
	string url,
	string savePath,
	int bufferSize = 81920,
	IProgress<double>? progress = null,
	CancellationToken cancellationToken = default
)

    参数

    url  String
    文件 URL，需为绝对地址。
    savePath  String
    本地保存路径（含文件名）；父目录不存在时会自动创建。
    bufferSize  Int32  (Optional)
    读写缓冲区大小（字节），默认 81920（80 KB）。
    progress  IProgressDouble  (Optional)
    进度回调，接收 0.0 到 1.0 的进度值；传 null 表示不需要进度。
    cancellationToken  CancellationToken  (Optional)
    取消令牌，用于中途取消下载。

    返回值

    TaskResultStatus
    操作结果：成功时 Success 为 true； 被取消时返回 "下载已取消"；其他失败返回异常信息。

    备注

    采用流式读取（ResponseHeadersRead）， 内存占用恒定为一个缓冲区大小，不会把整个文件加载到内存。

    进度回调依赖服务端返回的 Content-Length 响应头； 如果服务端未提供该头（如分块传输），进度回调不会被触发，但下载仍会正常完成。

    进度值为累计已读字节数除以总长度，可能因网络抖动略有回退，属正常现象。
