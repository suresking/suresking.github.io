    ProgressExtensionsAsPercentageProgress 方法

    将 IProgressT（字符串）适配为 IProgressT（double）， 适用于百分比型进度报告，内部使用 "F0" 格式化为整数百分比。

    等价于 AsProgress<double>("进度 ", "%", v => v.ToString("F0"))。

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.20+9f5f0e39c286801d0347077a3bcbea48de44d8b3
    C#
    public static IProgress<double>? AsPercentageProgress(
	this IProgress<string>? progress,
	string prefix = "进度 ",
	string suffix = "%"
)

    参数

    progress  IProgressString
    字符串型进度报告器（可为 null）。
    prefix  String  (Optional)
    进度消息前缀，默认"进度 "。
    suffix  String  (Optional)
    进度消息后缀，默认"%"。

    返回值

    IProgressDouble
    double 类型的进度报告器；progress 为 null 时返回 null。

    备注

    在 Visual Basic 和 C# 中，这个方法可以当成为类型 IProgressString 的实例方法来调用。在采用实例方法语法调用这个方法时，请省略第一个参数。请参考 扩展方法 (Visual Basic) 或 扩展方法 (C# 编程指南) 获取更多信息。
