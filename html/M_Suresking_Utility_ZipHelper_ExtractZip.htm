    解压Zip文件到指定的目标文件夹

    参数

    archiveFilePath  String
    需要解压的Zip文件完整路径
    extractPath  String
    解压的目标文件夹路径
    overwriteFiles  Boolean  (Optional)
    是否覆盖已存在的文件，默认为true

    返回值

    ResultStatus
    解压操作的结果状态

    备注

    实际异常行为修正：

    • zip 路径或目标路径为空：抛 ArgumentException；
    • zip 文件不存在：不抛异常，返回 Invalid(String)；
    • 目标目录不存在：自动创建；
    • 解压过程中的其它异常：被捕获，返回 Invalid(String)。

    覆盖语义：overwriteFiles 为 false 时，若目标目录已存在同名文件， ExtractToDirectory(String, String, Boolean) 会抛出 IOException， 最终表现为返回失败状态，而**不会部分覆盖**（已解压的文件保留）。

    安全提示：本方法直接使用 .NET 内置解压，.NET 对条目路径做了 Zip Slip（路径穿越）防护； 但解压不可信 zip 仍建议校验目标路径位于 extractPath 之下。

    异常

    ArgumentException当参数无效时抛出
