    InitializableViewModelBase 类

    提供支持异步初始化的 ViewModel 基类。

    继承自 ObservableObject，实现 IInitializable 接口，

    适用于需要在访问时既要构造函数又要异步初始化的场景。

    备注

    核心特性：

    • 状态感知：通过 IsInitialized 属性判断是否已完成初始化。
    • 按需加载：支持在首次使用时才触发初始化，延迟资源消耗。
    • 并发安全：EnsureInitializedAsync(CancellationToken) 方法保证多线程环境下只执行一次初始化。
    • 懒加载模式：适合 ViewModel 场景，页面打开时才加载数据，避免应用启动时的性能压力。

    典型使用流程：

    // 页面导航时调用 await viewModel.EnsureInitializedAsync(); // 此时可以安全使用 viewModel 的数据

    设计说明：

    此接口只暴露"确保已初始化"这一语义，不暴露"执行初始化"的具体动作。 实际初始化逻辑由实现类自行定义（在 InitializableViewModelBase 中为 protected abstract InitializeAsync），外部调用方无需也不应直接触发。

    属性

    ErrorMessage 获取或设置在初始化失败时的错误消息。 初始化成功后，此属性会被重置为 null。
    HasError 获取或设置一个值，该值指示初始化过程中是否发生了错误。 当此属性为 true 时，可通过 ErrorMessage 属性获取详细的错误描述。
    IsInitialized 获取一个值，该值指示 ViewModel 是否已完成初始化。
    IsLoading 获取或设置一个值，该值指示当前是否正在加载数据。 当此属性为 true 时，通常应在 UI 上显示加载指示器。
    LoadingMessage 获取或设置加载过程中显示的提示消息。 默认值为 "正在加载..."，在初始化过程中会自动更新为包含显示名称的文本。
    RetryLoadCommandGets an IAsyncRelayCommand instance wrapping RetryLoadAsync.

    方法

    EnsureInitializedAsync 确保 ViewModel 已完成初始化。 如果尚未初始化，则启动初始化过程；如果正在进行初始化，则等待其完成。 支持并发调用，多次调用不会触发重复初始化。
    GetDisplayName 获取当前 ViewModel 的显示名称。 默认实现会移除类名中的 "ViewModel" 后缀。
    InitializeAsync 当派生类重写时，执行实际的异步初始化逻辑。 在此方法中实现数据加载、服务调用等初始化操作。
