    ProgressExtensionsAsProgressT 方法

    将 IProgressT（字符串）适配为 IProgressT（任意类型）， 使库层的进度值自动转换为带描述文本的字符串进度。

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.22+a27276bb8ffde055e69ff608e98aafba279e1e99
    C#
    public static IProgress<T>? AsProgress<T>(
	this IProgress<string>? progress,
	string prefix = "已读取 ",
	string suffix = " 行",
	Func<T, string>? formatter = null
)

    参数

    progress  IProgressString
    目标进度报告器（可为 null），接收字符串格式的进度信息。 为 null 时方法返回 null，调用方可直接将返回值透传给库层。
    prefix  String  (Optional)
    进度消息的前缀，默认为"已读取 "
    suffix  String  (Optional)
    进度消息的后缀，默认为" 行"
    formatter  FuncT, String  (Optional)
    自定义格式化函数，默认使用 ToString()； 当 T 为 null 时默认输出 "null"。

    类型参数

    T
    进度值的类型（通常是 int、long、double 等数值类型，也可以是元组等复杂类型）

    返回值

    IProgressT
    如果 progress 为 null，则返回 null； 否则返回一个 IProgressT 适配器实例。

    备注

    在 Visual Basic 和 C# 中，这个方法可以当成为类型 IProgressString 的实例方法来调用。在采用实例方法语法调用这个方法时，请省略第一个参数。请参考 扩展方法 (Visual Basic) 或 扩展方法 (C# 编程指南) 获取更多信息。

    备注

    此方法支持可空进度报告器，适合 Service 层和库层都使用 IProgressT 的场景。

    使用示例： public async Task ProcessAsync(IProgress<string>? progress) { // 使用默认格式：已读取 {value} 行 await library.ReadDataAsync(progress.AsProgress<int>()); // 自定义前后缀 await library.ExportAsync(progress.AsProgress<long>("导出进度：", "%")); // 自定义格式化 await library.ProcessAsync(progress.AsProgress<double>( prefix: "完成 ", suffix: " %", formatter: v => v.ToString("F2") )); }
