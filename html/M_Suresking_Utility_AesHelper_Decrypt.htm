    AesHelperDecrypt(String, Byte) 方法

    由给定的字节数组密文解密。

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.22+a27276bb8ffde055e69ff608e98aafba279e1e99
    C#
    public static string Decrypt(
	string key,
	byte[] inputBytes
)

    参数

    key  String
    密钥；任意字符串，内部按 UTF-8 字节补/截到 32 字节。支持中文。
    inputBytes  Byte
    密文字节数组。

    返回值

    String
    解密后的明文。

    备注

    使用与 EncryptStringToBytes(String, String) 相同的密钥与 IV 进行解密。 若密文非法（长度不是块大小整数倍、被篡改等），底层会抛出 CryptographicException。

    异常

    CryptographicException解密失败（如密钥不匹配、密文被篡改）。
