    StringBuilderExtensionsToDataTable(StringBuilder, String, Boolean, String, Boolean) 方法

    将 StringBuilder 中的表格数据转换为 DataTable

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.20+9f5f0e39c286801d0347077a3bcbea48de44d8b3
    C#
    public static DataTable ToDataTable(
	this StringBuilder sb,
	string columnSeparator = "\t",
	bool hasHeaderRow = true,
	string defaultColumnPrefix = "Column",
	bool removeEmptyLines = true
)

    参数

    sb  StringBuilder
    包含表格数据的 StringBuilder 实例
    columnSeparator  String  (Optional)
    列分隔符，默认为 Tab 键（\t）
    hasHeaderRow  Boolean  (Optional)
    第一行是否为表头，默认为 true
    defaultColumnPrefix  String  (Optional)
    当表头为空时使用的列名前缀，默认为 "Column"
    removeEmptyLines  Boolean  (Optional)
    是否移除空行，默认为 true

    返回值

    DataTable
    转换后的 DataTable，如果数据为空则返回空的 DataTable

    备注

    在 Visual Basic 和 C# 中，这个方法可以当成为类型 StringBuilder 的实例方法来调用。在采用实例方法语法调用这个方法时，请省略第一个参数。请参考 扩展方法 (Visual Basic) 或 扩展方法 (C# 编程指南) 获取更多信息。

    示例

    C#
    StringBuilder sb = new StringBuilder();
sb.AppendLine("Name\tAge\tCity");
sb.AppendLine("张三\t25\t北京");
sb.AppendLine("李四\t30\t上海");

// 使用默认的 Tab 分隔符
DataTable dt = sb.ToDataTable();

// 使用逗号分隔符
DataTable dt2 = sb.ToDataTable(columnSeparator: ",");
