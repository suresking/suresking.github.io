    StringExtensionContainsKey 方法

    用给定的分隔符拆分源字符串，并查找指定键值是否存在

    这个扩展设计初衷是因为颗粒会有多个瓶码，为了减少一个一对多的关系，数据库存储时将所有瓶码用半角逗号连接到一个大字符串

    需要时再拆分成列表进行逐项核对；而不直接source.Contains(key)，则是为了避免`K0031,K031`对`K003`的误判

    备注

    在 Visual Basic 和 C# 中，这个方法可以当成为类型 String 的实例方法来调用。在采用实例方法语法调用这个方法时，请省略第一个参数。请参考 扩展方法 (Visual Basic) 或 扩展方法 (C# 编程指南) 获取更多信息。

    备注

    逐段截取并 Trim(ReadOnlySpanChar) 后与 key 做**序数（区分大小写）比较**， 因此 "K003" 与 "k003" 视为不同项，且不会出现子串误判（"K003" 不会命中 "K0031"）。

    使用 ReadOnlySpanT 与 MemoryExtensions.SequenceEqual{T} 避免中间字符串分配。

    任一侧为 null、空或纯空白时返回 false。
