    NoticeFromQueue 方法

    创建一条队列操作通知，用于管理消息队列的生命周期和数据处理流程。

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.22+a27276bb8ffde055e69ff608e98aafba279e1e99
    C#
    public static Notice FromQueue(
	Object? content
)

    参数

    content  Object
    队列操作上下文对象。

    建议封装以下信息：

    • QueueAction：操作类型（如 Enqueue、Dequeue、Peek、Clear、BatchProcess 等）。
    • Item：入队的具体数据项（可选，Enqueue 时使用）。
    • Items：批量数据项集合（可选，批量操作时使用）。
    • QueueName：目标队列名称（可选，多队列场景时使用）。
    • Priority：消息优先级（可选，优先级队列场景时使用）。
    • MaxBatchSize：批处理最大数量（可选，控制批处理行为）。
    • Timeout：超时时间（可选，出队等待场景时使用）。

    返回值

    Notice
    类型为 Queue 的实例。

    备注

    典型使用场景：

    • Suresking特别说明：最简单的办法是仅仅传递一个字符串用于显示。
    • 生产者-消费者模式：生产者发送入队通知，消费者接收后处理数据。
    • 消息总线：通过队列实现组件间的异步解耦通信。
    • 任务调度：将待处理任务入队，由工作线程按序执行。
    • 事件缓冲：高频事件先入队，再批量或定时处理，避免资源争用。
    • 日志/审计队列：将日志消息入队，异步写入磁盘或远程服务。

    消费方应根据 content 中的操作类型执行相应的队列逻辑，并做好类型检查和异常处理。

    示例

    C#
    // 单条消息入队——最常见
var enqueue = Notice.FromQueue(new { Action = "Enqueue", Item = new MyMessage { Id = 1, Data = "Hello" } });

// 批量消息入队
var batchEnqueue = Notice.FromQueue(new 
{ 
    Action = "BatchEnqueue", 
    Items = new[] { msg1, msg2, msg3 },
    QueueName = "HighPriority"
});

// 出队请求
var dequeue = Notice.FromQueue(new { Action = "Dequeue", QueueName = "MainQueue", Timeout = 5000 });

// 清空队列
var clear = Notice.FromQueue(new { Action = "Clear", QueueName = "TempQueue" });

// 触发批处理
var batchProcess = Notice.FromQueue(new { Action = "BatchProcess", MaxBatchSize = 100 });

// 查看队列状态
var peek = Notice.FromQueue(new { Action = "Peek", QueueName = "MainQueue" });

// 消费端处理示例
if (notice.TryGetContent<QueueCommand>(out var cmd))
{
    switch (cmd.Action)
    {
        case "Enqueue":
            messageQueue.Enqueue(cmd.Item);
            break;
        case "Dequeue":
            var item = messageQueue.Dequeue(cmd.Timeout);
            // 处理出队数据...
            break;
        case "BatchProcess":
            var batch = messageQueue.DequeueBatch(cmd.MaxBatchSize);
            ProcessBatch(batch);
            break;
    }
}
