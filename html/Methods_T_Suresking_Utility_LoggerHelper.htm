    LoggerHelper 方法

    方法

    Critical(String, String, String, Int32) 记录严重错误级别日志。
    Critical(String, Exception, String, String, Int32) 记录严重错误级别日志（附带异常信息）。 会将异常消息和堆栈跟踪拼接到日志内容中。
    Debug 记录调试级别日志。
    DebugFormat 记录调试级别日志（支持字符串格式化）。
    Error(String, String, String, Int32) 记录错误级别日志。
    Error(String, Exception, String, String, Int32) 记录错误级别日志（附带异常信息）。 会将异常消息和堆栈跟踪拼接到日志内容中。
    ErrorFormat 记录错误级别日志（支持字符串格式化）。
    Info 记录信息级别日志。
    InfoFormat 记录信息级别日志（支持字符串格式化）。
    SetBackupCount 设置滚动备份文件保留数量。
    SetConsoleOutput 设置是否同时输出到控制台。
    SetEnableAsync 设置是否启用异步日志写入。 关闭后日志将在调用线程同步写入。
    SetLogLevel 设置日志级别。低于该级别的日志将被忽略。
    SetLogRootPath 设置日志根目录，并自动更新当前日志文件路径。 若目录不存在则自动创建。
    SetMaxFileSize 设置单个日志文件的最大字节数，超过后触发滚动。
    SetShowCallerInfo 设置是否在日志中显示调用者信息（类名、方法名、行号）。
    Shutdown 关闭日志器并释放资源。 停止后台线程，处理队列中剩余消息，并释放队列。 应在应用程序退出前调用，以避免日志丢失。
    Warning 记录警告级别日志。
