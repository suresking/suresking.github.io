    检测字符串中是否包含列表中的关键词

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.22+a27276bb8ffde055e69ff608e98aafba279e1e99
    C#
    public static bool Contains(
	this string? s,
	IEnumerable<string> keys,
	bool ignoreCase = true
)

    参数

    s  String
    源字符串；为 null 或空时返回 false。
    keys  IEnumerableString
    关键词列表；为空时返回 false。每个关键词会做正则转义，按字面量匹配。
    ignoreCase  Boolean  (Optional)
    是否忽略大小写，默认 true。

    返回值

    Boolean
    源字符串包含任意一个关键词时返回 true，否则返回 false。

    备注

    在 Visual Basic 和 C# 中，这个方法可以当成为类型 String 的实例方法来调用。在采用实例方法语法调用这个方法时，请省略第一个参数。请参考 扩展方法 (Visual Basic) 或 扩展方法 (C# 编程指南) 获取更多信息。

    备注

    将关键词排序去重后拼成 k1|k2|k3 的正则，并配合 Compiled 编译， 结果按“模式串_是否忽略大小写”缓存在 _regexCache 中，避免重复编译。

    正则设置了 100 毫秒超时，防止极端输入导致回溯爆炸；超时会抛出 RegexMatchTimeoutException。

    注意：本方法只判断“是否包含任一关键词”，不会区分词边界； 若需精确匹配分隔符列表中的某一项，请使用 ContainsKey(String, String, Char)。
