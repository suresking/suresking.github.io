    命名空间： Suresking.Utility

    C#
    public static string ToMD5(
	this string? input
)

    参数

    input  String
    待计算散列的字符串；为 null 或空时返回空字符串。

    返回值

    String
    32 位十六进制大写 MD5 摘要；输入为空时返回 Empty。

    备注

    在 Visual Basic 和 C# 中，这个方法可以当成为类型 String 的实例方法来调用。在采用实例方法语法调用这个方法时，请省略第一个参数。请参考 扩展方法 (Visual Basic) 或 扩展方法 (C# 编程指南) 获取更多信息。

    备注

    使用 UTF-8 编码；.NET 8+ 走 HashData(Byte)，否则回退到 Create。

    安全提示：MD5 已存在碰撞漏洞，不应再用于密码存储或安全签名；密码散列请使用 PBKDF2/bcrypt/scrypt/Argon2。
