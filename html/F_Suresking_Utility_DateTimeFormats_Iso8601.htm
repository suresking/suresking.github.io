    DateTimeFormatsIso8601 字段

    类ISO 8601格式。注意：此格式仅输出当前时间的字符串表示，不会自动转换为UTC时间。 若需严格符合ISO 8601，请先将DateTime转为UniversalTime后再格式化。

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.22+a27276bb8ffde055e69ff608e98aafba279e1e99
    C#
    public static readonly string Iso8601

    字段值

    String
    格式字符串 "yyyy-MM-ddTHH:mm:ssK"；K 表示时区偏移。

    备注

    K 说明符的输出取决于 Kind：

    • Utc：输出 Z（如 ...55Z）；
    • Local：输出本地时区偏移（如 ...55+08:00）；
    • Unspecified：输出空（无时区后缀）。

    因此“类 ISO 8601”不保证严格合法：Unspecified 时输出缺少时区部分。严格场景请用 DateTimeOffset.ToString("O") 或 ToUniversalTime 后再格式化。
