    RegexHelper 类

    正则表达式帮助类，提供高性能的缓存编译功能。 对于频繁使用的正则表达式模式，会自动缓存编译后的实例以提升性能。 对于一次性使用的模式，提供静态方法直接调用。 所有正则操作均设置超时保护，防止 ReDoS 攻击。

    备注

    使用示例：

    // 预定义的快速验证 bool isEmail = RegexHelper.IsEmail("test@example.com"); // 使用缓存编译（适合重复使用的模式） bool isMatch = RegexHelper.IsMatchCached("input", @"\d+"); // 一次性使用（适合偶尔使用的模式） string[] matches = RegexHelper.Matches("input", @"\d+");

    缓存注意事项：缓存没有自动淘汰，仅当条目数超过上限（默认 512）时整体清空。 请勿将用户输入或动态拼接的字符串作为 pattern 传入缓存方法，否则缓存会无限增长且频繁清空。 动态 pattern 请使用非缓存的 IsMatch(String, String, RegexOptions)、Match(String, String, RegexOptions) 等方法。

    双框架说明：本类同时支持 net6.0 与 net8.0。 net8.0 下预定义缓存正则不强制Compiled（.NET 7+ 解释器已高度优化， Compiled 在冷启动场景反而更慢）；net6.0 下保留 Compiled 以获得长期运行收益。

    属性

    CacheCount获取当前缓存的正则表达式数量。

    方法

    ClearCache清除所有缓存的正则表达式实例。
    ExtractMatches使用缓存编译的正则表达式提取所有匹配项。
    IsChinese验证字符串是否全部由基本汉字区中文字符组成。
    IsDate验证字符串是否为有效的日期格式（YYYY-MM-DD）。
    IsEmail验证字符串是否为有效的电子邮件地址。
    IsIdCard验证字符串是否为有效的中国大陆身份证号（仅校验格式）。
    IsIpAddress验证字符串是否为有效的 IP 地址格式（简单模式，不验数值范围）。
    IsLicensePlate验证字符串是否为有效的中国大陆车牌号。
    IsMatch验证字符串是否与指定的正则表达式匹配（不使用缓存）。
    IsMatchCached使用缓存编译的正则表达式验证字符串是否匹配指定模式。
    IsPhone验证字符串是否为有效的中国大陆手机号。
    IsTime验证字符串是否为有效的时间格式（HH:MM:SS）。
    IsUrl验证字符串是否为有效的 URL 地址。
    IsValidIpv4验证字符串是否为有效的 IPv4 地址（严格模式）。
    IsValidIpv6验证字符串是否为有效的 IPv6 地址。
    Match在字符串中搜索第一个正则表达式匹配项。
    Matches在字符串中搜索所有正则表达式匹配项。
    MatchGroups获取正则表达式的所有分组匹配结果（不包含整体匹配）。
    MatchGroupsWithNames获取正则表达式的所有命名分组匹配结果（不含整体匹配）。
    MatchWithGroupNames获取正则表达式的完整匹配结果和所有命名分组。
    Replace使用正则表达式替换字符串中的匹配项。
    ReplacePattern使用缓存编译的正则表达式替换匹配项。
    SplitByPattern使用缓存编译的正则表达式分割字符串。

    字段

    ChinesePattern中文字符正则表达式模式（仅基本汉字区）。
    DatePattern日期格式正则表达式模式（YYYY-MM-DD，仅格式）。
    EmailPattern电子邮件正则表达式模式。
    IdCardPattern中国大陆身份证号正则表达式模式。
    IpAddressPatternIP 地址简单正则表达式模式（仅格式）。
    Ipv4Pattern精确的 IPv4 地址正则表达式模式。
    LicensePlatePattern中国大陆车牌号正则表达式模式。
    PhonePattern中国大陆手机号正则表达式模式。
    TimePattern时间格式正则表达式模式（HH:MM:SS，仅格式）。
    UrlPatternURL 网址正则表达式模式。
