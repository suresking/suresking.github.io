)

    参数

    url  String
    文件 URL，需为绝对地址。

    返回值

    ResultStatus
    操作结果：成功时 Success 为 true 且消息为响应正文； 发生任何异常（网络错误、非 2xx 状态码等）时返回 Failed。

    备注

    此方法会阻塞当前线程，异步场景请使用 TryGetContentAsync(String)。

    返回的是字符串内容，适用于文本文件 / 接口响应；二进制内容请使用下载方法。
