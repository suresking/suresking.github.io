    AesHelperCreateDecryptor 方法

    创建一个 AES 解密器（ICryptoTransform），供流式解密使用。

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.22+a27276bb8ffde055e69ff608e98aafba279e1e99
    C#
    public static ICryptoTransform CreateDecryptor(
	string key
)

    参数

    key  String
    密钥；任意字符串，内部按 UTF-8 字节补/截到 32 字节。支持中文。

    返回值

    ICryptoTransform
    可用于 CryptoStream 的解密器。

    备注

    用途：与 CreateEncryptor(String) 对称，把“密钥处理 + 固定 IV + AES 实例创建” 集中在这里，供 ZipHelper.DecryptAndDecompressFromFile 等流式解密场景使用。

    与 Decrypt(String, Byte) 的一致性：使用相同的密钥处理规则和相同的固定 IV， 因此只要密码正确，流式解密结果与 Decrypt(String, Byte) 一致。

    异常：密码错误或密文损坏时，异常不会在本方法抛出，而是在 CryptoStream 读取/释放时抛出 CryptographicException，由调用方捕获处理。
