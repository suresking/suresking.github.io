    public static string ToFormattedString(
	this DateTime dateTime,
	string format,
	IFormatProvider? provider = null
)

    参数

    dateTime  DateTime
    日期时间
    format  String
    格式化字符串，可使用 DateTimeFormats 中的常量
    provider  IFormatProvider  (Optional)
    格式提供程序，默认为当前线程的 CultureInfo

    返回值

    String
    按 format 与 provider 格式化后的字符串。

    备注

    在 Visual Basic 和 C# 中，这个方法可以当成为类型 DateTime 的实例方法来调用。在采用实例方法语法调用这个方法时，请省略第一个参数。请参考 扩展方法 (Visual Basic) 或 扩展方法 (C# 编程指南) 获取更多信息。

    备注

    本方法是唯一显式支持 IFormatProvider 的扩展方法；若需要不受区域设置影响的稳定输出， 请传入 InvariantCulture。

    provider 为 null 时使用当前线程区域性，与 ToString(String) 行为一致。
