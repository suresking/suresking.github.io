    EnumItemTEnumFromEnum 方法

    从枚举类型生成所有枚举项的列表，用于 UI 绑定。

    列表顺序与 GetValuesTEnum 一致，即按枚举值大小升序排列。

    // 在 ViewModel 中作为数据源
public List<EnumItem<StudentCategory>> Categories { get; } =
    EnumItem<StudentCategory>.FromEnum();
