    ZipHelperZipDirectory 方法

    压缩一个文件夹到指定的Zip文件

    Definition

    命名空间： Suresking.Utility
    程序集： Suresking.Utility (在 Suresking.Utility.dll 中) 版本：1.3.22+a27276bb8ffde055e69ff608e98aafba279e1e99
    C#
    public static ResultStatus ZipDirectory(
	string sourcePath,
	string destinationPath,
	string? archiveFileName = null
)

    参数

    sourcePath  String
    需要压缩的源目录路径
    destinationPath  String
    目标Zip文件保存的目录路径
    archiveFileName  String  (Optional)
    自定义的压缩文件名，为null时使用时间戳命名

    返回值

    ResultStatus
    压缩操作的结果状态

    备注

    实际异常行为修正：

    • 源/目标路径为空：抛 ArgumentException；
    • 源目录不存在：不抛异常，返回 Invalid(String)（消息含路径）；
    • 目标目录不存在：自动创建；目标文件已存在：先删除再创建；
    • 压缩过程中的其它异常：被捕获，返回 Invalid(String)。

    默认文件名格式为 yyyyMMddHHmmssffff（精确到 0.1 毫秒），扩展名 .zip。 若 archiveFileName 不含 .zip 后缀，是否补全会由 CreateFromDirectory(String, String) 决定， 建议调用方传入完整文件名。

    压缩内容为源目录的**直接内容**（不包含源目录自身层级，即源目录作为 zip 根）。

    异常

    ArgumentException当源路径或目标路径无效时抛出
    DirectoryNotFoundException当源目录不存在时抛出
